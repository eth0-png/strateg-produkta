# Особенности Claude Code

- Хук `SessionStart` уже выполнил `sa.py resume`, сводка в контексте. Хук `Stop` после каждого ответа записывает расход токенов в `cost.jsonl` проекта. Сам эти команды не вызывай.
- Хук `PreToolUse` (`sa.py guard`) не пускает WebFetch и браузер на домены вне `policy.md`, запрещает запись в `materials/`, `method/`, `AGENTS.md`, `CLAUDE.md`, `.claude/`, `.mcp.json`, а браузеру ввод текста и выполнение кода. В оболочке (Bash, PowerShell) он пропускает только `python tools/sa.py ...` и связку через `&&`. Отказ хука это правило, а не сбой: прочитай причину и действуй по ней.
- Процедуры шагов подключены как скиллы `framing`, `research`, `options`, `strategy`, `decision`, `revise`, а также `data`, `interview`, `ux`. Вместо чтения файла процедуры вызывай скилл с тем же именем.
- Субагенты `collector`, `judge`, `browser`, `persona`, `strategist`, `red-team` вызываются через инструмент Agent. В задании субагенту давай пути к файлам и идентификаторы, а не содержимое файлов: так дешевле, а сырой текст источников не попадает в основной контекст.
- Playwright подключён через `.mcp.json`. Его инструменты вызывает только `browser`, основная сессия их не вызывает: иначе текст страниц попадёт в основной контекст.
- Независимые источники отдавай нескольким `collector` в одном сообщении, они работают параллельно.
- Рекомендуемая модель основной сессии: Sonnet (`/model sonnet`).
