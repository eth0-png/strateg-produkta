# Тестовая задача: KION

Учебная постановка для отладки агента до выхода брифа МегаФона. Это не заказ МТС и не их данные: используются только открытые источники.

## Запрос для агента (вставлять дословно)

> Я руковожу продуктом онлайн-кинотеатра KION. Много пользователей уходят после пробного периода и промо-подписок. Нужно понять почему и что делать: менять продукт, менять коммуникацию, или оставить как есть. Результат нужен директору по продукту. Внутренних данных у меня для тебя нет, работаем на открытых источниках.

## Почему KION

1. Цифровой продукт оператора за пределами телекома, продаётся отдельно и в связке с подпиской оператора.
2. Есть пробный период и промо-подписки, вопрос удержания после них реален.
3. Открытые данные проверены 7 ноября 2026: публичный фид отзывов App Store (`https://itunes.apple.com/ru/rss/customerreviews/page=1/id=1451612172/sortby=mostrecent/json`, по 50 отзывов на страницу), страница RuStore (`https://www.rustore.ru/catalog/app/ru.mts.mtstv`), сайт kion.ru, пресс-релизы ON Медиа.
4. Не МегаФон: не пересекается с демо-брифом.

## Как используем

- Сквозной прогон 12 ноября и контрольная точка 15 ноября идут на этом запросе.
- Для сравнения тот же запрос отдаём обычному чату одним сообщением.
