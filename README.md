# Стратег продукта

ИИ-агент для руководителя цифрового продукта. Проводит путь от размытого запроса до обоснованной продуктовой и коммуникационной стратегии: ставит задачу, собирает открытые источники с сохранением ссылок и цитат, честно называет пробелы, предлагает не меньше трёх вариантов с сильными возражениями и останавливается для выбора человека.

Это папка с инструкциями, методикой и скриптами, а не отдельная программа. Её открывают в Claude Code, Cursor или Codex.

## Что нужно

| Что | Зачем | Платно ли |
|---|---|---|
| Python 3.10+ | `tools/sa.py`: реестры, проверки, журнал, стоимость. Только стандартная библиотека, ставить ничего не нужно | нет |
| Claude Code 2.1.317 или новее | основная среда: хуки, скиллы, субагенты. В старых версиях алиас `haiku` даёт Haiku 4.5, который в 10 раз дороже Haiku 5.5. Версию показывает `claude --version`, обновление: `claude update` | подписка Claude Pro или Max, либо ключ API |
| или Cursor, Codex | переносимость: читают `AGENTS.md`, хуков и субагентов нет | по тарифу среды |
| Интернет | открытые источники | нет |
| Node.js 18+ и Chromium для Playwright | только для прохода по сайту и снимков экранов (скилл `ux`). Без них экраны снимает человек | нет |

Chromium для Playwright ставится один раз, около 170 МБ:

```bash
npx -y -p @playwright/mcp@0.0.83 playwright install chromium
```

Сервер `playwright` из `.mcp.json` разрешён в `.claude/settings.json`. Если при первом открытии папки Claude Code всё же спросит о нём, разрешите. Браузер работает без окна.

Если браузер не запускается с ошибкой `spawn UNKNOWN` (так было на Windows 11 26H2: полный Chromium не стартует из-за манифеста), укажите облегчённую сборку той же версии, она ставится той же командой. Команда для командной строки Windows (cmd), не для PowerShell и не для bash. Номер в имени папки `chromium_headless_shell-…` может отличаться: посмотрите его в `%LOCALAPPDATA%\ms-playwright`.

```bat
setx PLAYWRIGHT_MCP_EXECUTABLE_PATH "%LOCALAPPDATA%\ms-playwright\chromium_headless_shell-1247\chrome-headless-shell-win64\chrome-headless-shell.exe"
```

После этого перезапустите Claude Code.

Ключи и секреты в репозитории не хранятся и не нужны. Поиск в Claude Code входит в подписку, в ценах API он стоит 10 долларов за 1000 запросов.

## Первый запуск

1. Склонируйте репозиторий и перейдите в его папку. Проверьте установку: `python tools/test_sa.py` должен ответить «OK: все проверки sa.py прошли».
2. В этой папке запустите `claude`. Подтвердите доверие к папке: без него Claude Code не применит разрешения из `.claude/settings.json` и будет спрашивать о каждой команде `sa.py`.
3. Выберите модель основной сессии: `/model sonnet`. Сильная модель подключается сама только для вариантов и стратегии.
4. Опишите задачу обычными словами. Пример запроса в `docs/test-task.md`.
5. Агент задаст до трёх вопросов, покажет бриф и дальше будет останавливаться в пяти точках выбора: бриф, план и бюджет, выбор варианта, стратегия, ответственные и сроки.

В Cursor или Codex откройте папку и напишите задачу. Агент прочитает `AGENTS.md` и начнёт с `python tools/sa.py resume`.

## Сколько стоит и сколько длится

Проект до стратегии на наших прогонах: от 5,5 до 7 долларов в ценах API и от 25 до 35 минут работы модели. С возвратом к сбору, PDF и снимками от человека выходило до 9 долларов и 42 минут. На брифе МегаФона с заданным составом итогового документа из пяти частей: от 12 до 13 долларов и около 47 минут. Сверху время человека в точках выбора. Около половины расхода приходится на ведущую сессию Sonnet. Opus работает только в `strategist`, от 2,3 до 3,3 доллара. В подписке Claude это расход лимита, а не деньги: на тарифе Max 5x полный прогон занял около 7% пятичасового окна. Расход против бюджета из `policy.md` виден в `sa.py resume`, при превышении агент останавливается и спрашивает. Замеры по шагам в `docs/fixes.md`, сравнение с обычным чатом в `docs/comparison.md`.

## После решения

- Пришли новые данные или вы нашли ошибку в факте: напишите об этом агенту. Он найдёт, какие выводы, решения и обязательства на это опираются, и пересмотрит только их. История пересмотров в `out/revisions.md`.
- «Что с обязательствами?»: агент покажет просроченное, ближайшие сроки и основания, которые отозваны или устарели. То же без агента: `python tools/sa.py due`.

## Продолжить после перерыва

Откройте новый чат в той же папке. В Claude Code сводка «где остановились» появится сама. В другой среде напишите «продолжи работу». Агент продолжит с сохранённого шага и не будет повторять уже сделанное. В сводке видно, сколько решающих вопросов закрыто и есть ли сейчас ошибки проверки.

## Остановить, уточнить, исправить

- «Стоп» в любой момент. Агент запишет, с чего продолжить.
- Уточнить задачу можно в любой точке выбора или просто сообщением.
- Любой рабочий файл в `projects/<id>/work/` можно поправить руками. Агент перечитает его и учтёт правку.

## Что видно

- `projects/<id>/out/strategy.md`: итог для руководителя.
- `projects/<id>/out/report.md`: что сделал агент, источники, цепочки оснований, участие человека, ошибки, время и стоимость.
- `python tools/sa.py check`: проверка, что у фактов есть источники и цитаты, на каждый решающий вопрос есть ответ или названный пробел, варианты полные, обещания опираются на продукт.
- `python tools/sa.py judge`: пакеты фактов для судьи. Субагент `judge` на Haiku проверяет, что утверждение следует из цитаты и её окружения в копии источника. Для снимков и PDF он открывает сам файл и сверяет ещё и цитату. Замер в `docs/judge.md`.
- `python tools/sa.py cost`: расход токенов по моделям в ценах API.
- `python tools/sa.py trace F-3`: откуда взялось утверждение и что на него опирается.
- `python tools/sa.py profile materials/<файл>.csv`: профиль таблицы до расчётов, путь считается от папки проекта `projects/<id>/`. Строки, типы, пропуски, периоды, единицы, дубли.

## Интервью, данные, интерфейсы

- Материалы проекта лежат в `projects/<id>/materials/`, папку создаёт агент при постановке задачи. Выгрузку или таблицу положите туда в CSV или JSON. Агент сначала сделает профиль: какой период покрывают данные, где пропуски, в чём единицы. Только потом считает.
- Реальные интервью проводите вы, агент готовит гайд с текстом согласия и разбирает расшифровки. Расшифровки кладите в `projects/<id>/materials/interviews/` обезличенными, с кодами R1, R2. Если в файле есть почта или телефон, агент остановится.
- Синтетические интервью агент проводит сам: модельные респонденты на Haiku в отдельном контексте, без доступа к гипотезам. Их ответы становятся только гипотезами с планом проверки, доли по ним `check` не пропускает.
- Путь пользователя по сайту агент проходит сам в браузере: только переходы и нажатия, без ввода данных, только домены из `policy.md`. Экраны приложения снимите сами и положите в `projects/<id>/materials/ux/`. Разбор опирается только на то, что видно на снимке.

## Как устроено

| Где | Что |
|---|---|
| `AGENTS.md` | постоянные инструкции для всех сред |
| `CLAUDE.md` | особенности Claude Code |
| `method/` | методика и шаблоны документов |
| `.claude/skills/` | процедуры шагов: `framing`, `research`, `options`, `strategy`, `decision`, `revise`. Внутри сбора: `data` (профиль и расчёты), `interview` (интервью и модельные респонденты), `ux` (разбор интерфейса) |
| `.claude/agents/` | субагенты: `collector`, `judge`, `browser`, `persona` (Haiku), `strategist` (Opus), `red-team` (Sonnet) |
| `.claude/settings.json` | хуки: сводка при старте, защита доменов, файлов, браузера и оболочки перед вызовом инструмента, учёт стоимости после ответа |
| `.mcp.json` | Playwright MCP с закреплённой версией: браузер для прохода по сайту, отдельный профиль без входа в аккаунты |
| `tools/sa.py` | командная строка агента |
| `projects/<id>/` | материалы, состояние, реестры, журналы и итог одного проекта |
| `docs/` | ход разработки: ошибки агента и исправления по прогонам (`fixes.md`), сравнение с обычным чатом (`comparison.md`), сравнение с похожими проектами (`analogs.md`), описание работы для жюри (`description.md`), состояние работы (`status.md`) |

Ключевые решения и план описаны в `DESIGN.md`.

```bash
python tools/test_sa.py
```

## Разработка агента

Хук защиты запрещает менять `AGENTS.md`, `CLAUDE.md`, `.claude/` и `method/` во время работы, чтобы текст из источника не мог переписать правила. Чтобы менять сам агент, создайте в корне пустой файл `.sa-dev` вручную (он в `.gitignore`). Перед прогонами его убирают. Сессии разработки исключаются из стоимости проекта: `python tools/sa.py cost --exclude <id сессии>`.

## Ограничения

- В Cursor и Codex нет хуков и субагентов: сводку и учёт расхода агент вызывает командами `sa.py`, расход вносится вручную. Проверка доменов там работает только в `sa.py fetch`, запрет записи держится на инструкции.
- В оболочке хук пропускает только `python tools/sa.py ...`. Команду `git` и любую другую выполняет человек.
- Судья это модель, а не скрипт. Его «нет» и «частично» это предупреждения, а «да» по снимку или PDF не доказательство: файл лежит в `materials/`, цитату можно открыть и сверить глазами. Выводы расчётов, экраны с разметкой и страницы без копии судья не проверяет.
- Агент может дописать домен в `policy.md`. Правило требует согласия человека, но технически это не запрещено.
- Проверка защиты описана в `docs/fixes.md`: в материалы проекта подложили вставку с командой для ИИ, агент её не выполнил и сообщил человеку.
- Стоимость считается в ценах API по логам Claude Code. Внутренние вызовы модели внутри WebFetch в логах не видны и не учтены.
- Цитаты из PDF, со снимков и со страниц, прочитанных через WebFetch, скрипт не сверяет, `check` об этом предупреждает. Для PDF и снимков предупреждение снимает судья, если нашёл цитату в файле. Цитаты с экранов сверяются по текстовой разметке страницы. На снимке без разметки (экран приложения) не сверяются.
- Наблюдения о расположении и выделении элементов делает модель по снимку. Скрипт их не проверяет, но каждое ссылается на снимок, и его можно открыть.
- Браузер может уйти на чужой домен по нажатию на странице: хук проверяет только явные переходы по адресу. По правилу `browser` такой экран не снимает и останавливается. На прогоне так и вышло: «Оформить подписку» на kion.ru ведёт на `login.mts.ru`.
- `profile` читает CSV, TSV и JSON. Таблицу Excel сохраните как CSV.
- Playwright подключён только для Claude Code. В Cursor и Codex экраны снимает человек.
