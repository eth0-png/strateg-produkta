# Анализ данных

Всё, что считается, считает скрипт. Каждое число в документах ссылается на факт из вывода расчёта.

## Профиль до расчётов

1. Файл зарегистрирован как источник (`fetch` или `add-source`). Таблицу Excel человек сохраняет как CSV.
2. `python tools/sa.py profile materials/<файл>.csv`. Страницы одной выгрузки можно дать одной командой. Профиль сохранится в `work/calc/profile-<имя>.txt` и станет источником `S-n`.
3. По профилю до любых расчётов проверь:
   - период: какие даты покрывают данные и подходит ли это вопросу. Лента последних отзывов может покрывать месяц, а не год.
   - пропуски и пустые месяцы: считать по пустому нельзя, молча выбросить тоже.
   - единицы: рубли или тысячи, с НДС или без, доля или процент. Не указаны: запиши допущение.
   - дубли строк и повторы идентификаторов.
   - смешанные типы: числа вперемешку с текстом, разные форматы дат.
4. Что важно для вывода, регистрируй фактом из профиля: `sa.py claim F "Отзывы покрывают период с ... по ..." --src S-n --quote "Период с ..."`. Ограничения данных запиши в пробелы картины.

## Метод под вопрос

| Вопрос | Метод |
|---|---|
| Сколько, какая доля | доля с числом наблюдений и интервалом |
| Изменилось ли | сравнение с базой: тот же период раньше, другой сегмент, до и после |
| Почему, на что жалуются | качественное кодирование текстов, затем доли тем |
| Связаны ли две величины | связь только как гипотеза `H`: она не доказывает причину |

## Расчёт

1. В начале скрипта комментарием определение показателя: числитель, знаменатель, период, единица, что исключено и почему.
2. Доля всегда с n и 95% интервалом Уилсона:

```python
def wilson(k, n, z=1.96):
    p = k / n
    c = (p + z * z / (2 * n)) / (1 + z * z / n)
    h = z * (p * (1 - p) / n + z * z / (4 * n * n)) ** 0.5 / (1 + z * z / n)
    return c - h, c + h
```

3. Качественное кодирование (отзывы, открытые ответы):
   - сначала словарь тем с правилами отнесения в скрипте, потом подсчёт.
   - один текст может попасть в несколько тем. Печатай и долю «не отнесено».
   - по каждой теме печатай 3 примера с фиксированным `random.seed`, чтобы человек проверил кодирование глазами.
4. Запуск: `python tools/sa.py calc <скрипт>.py --inputs S-5,S-6`. Факты берутся из вывода с цитатой.
5. Подпись числа в документах: «среди 500 отзывов App Store с 11 октября по 5 ноября», а не «пользователи».

`sa.py check` предупреждает о числах без метки в рабочих документах.
